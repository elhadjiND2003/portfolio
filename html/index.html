À propos de moi

QA Automation Engineer · Software Quality Engineer · AI Test Automation

Je suis un QA Automation Engineer avec une forte orientation Software Engineering. Mon parcours m'a permis de travailler sur différentes dimensions de la qualité logicielle : tests fonctionnels, automatisation, API, mobile, performance, sécurité, CI/CD et validation de systèmes intégrant l'intelligence artificielle.

Je ne me limite pas à exécuter des tests : je cherche à comprendre comment fonctionne une application, identifier les risques, automatiser les scénarios répétitifs, intégrer les tests dans le cycle de développement, détecter les régressions automatiquement et produire des preuves et des rapports exploitables. Cette approche m'a naturellement amené à développer mes propres outils d'automatisation et à explorer les AI Agents dédiés au testing.

Approche

Ma démarche QA

Une approche structurée en 8 étapes pour améliorer continuellement la qualité logicielle.

01
Understand

Comprendre le besoin métier, les utilisateurs, l'architecture, les règles et les risques.

02
Plan

Définir les scénarios, les données de test, les cas nominaux, limites et négatifs.

03
Test

Exécuter tests fonctionnels, API, Web, Mobile, performance et sécurité.

04
Automate

Identifier les scénarios répétitifs et les automatiser.

05
Integrate

Intégrer les automatisations dans la CI/CD.

06
Report

Produire des rapports exploitables.

07
Analyze

Analyser les échecs et identifier les régressions.

08
Improve

Améliorer la couverture, les scénarios, les automatisations et les pipelines.
